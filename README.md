# 価格ウォッチ

**サイト: https://yamagishi0046-web.github.io/price-watch/**

楽天市場の48カテゴリ（PC周辺機器・オーディオ・キッチン家電・生活家電・キャンプ用品・ペット用品・デスク周り）の商品価格を毎日1回自動で記録し、相場（中央値）の推移と値下がりから「いま買うべきか（買い時／平常／待ち）」を判定して公開しています。

- 価格はレビュー数の多い商品を毎日集計したもので、各ページの数字は集計日つきで載せています
- 記事はプログラムが毎日検査（PR表記・誇大表現・データ鮮度・数値の整合）してから公開します
- 当サイトはアフィリエイトプログラムによる収益を得ています
