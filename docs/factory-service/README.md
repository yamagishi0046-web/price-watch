## 1. まず、つなぎの方への返信（文面案）

先方は「ご準備は可能でしょうか？」と聞いています。ここは即答が効きます。

> ○○さん
>
> ご連絡ありがとうございます。とてもありがたいお話です。
> 資料のご用意、可能です。○月○日までにお送りします。
>
> 内容は「目指すゴール／現在の状況／今後の方針」に加えて、
> 今こちらで答えを持てていない論点も、隠さず並べる形にします。
> 現状は仮説段階で有償顧客はゼロですので、取り繕うより、
> どこが埋まっていないかを見ていただいた方がご指摘をいただけると考えています。
>
> 当日お願いしたいのは主に2点です。
> ① 現場ヒアリングに伺える工場を1〜2社ご紹介いただけないか
> ② いただいた予備調査のお話について、いま使うべきかのご相談
>
> ご紹介先には売り込みは一切せず、30分のヒアリングのみ、
> 必要ならNDAを締結し、伺った内容は必ず○○さんにも共有します。
>
> 日程は○月○日以降でしたら調整可能です。よろしくお願いいたします。

ポイント:

- 「準備できます」を最初に言い切る（相手は段取りを進めたい）
- 顧客ゼロを自分から先に開示する（後で発覚するのが最悪）
- 紹介する側のリスク（変な人を紹介した、と思われること）を先に潰す

## 2. 面談までに埋めること

### 2-1. 資料の【要記入】一覧

| スライド | 埋める内容 |
|---|---|
| 1. 表紙 | サービス名／屋号、氏名、日付、相手の会社名 |
| 3. 自己紹介 | 現職・職種／年数、製造業との接点、週の稼働時間・資金、**なぜ工場向けなのか（動機）** |
| 6. 解決仮説 | 現時点のプロトタイプの状態／触れるデモの有無 |
| 8. モデル | 初期導入◯万円、月額◯万円／拠点、従業員規模、業種、地域 |
| 9. 現在の状況 | プロトタイプの到達点、これまでに話を聞けた工場の件数（0件なら0と書く） |
| 13. お願い | 紹介してほしい工場の条件（規模・業種・地域） |
| 14. リスク | 何で差をつけるか、使える時間／資金／体制 |

動機（なぜ工場か）は、コンサル相手なら**ほぼ確実に聞かれます**。
「儲かりそうだから」でも構いませんが、言葉にしておかないとその場で詰まります。

### 2-2. 資料には載せず、自分の中で決めておく数字

- 予備調査に出せる**上限額**（その場で決めると必ず高い方に流れます）
- 無償PoCに投じてよい工数の上限
- いつまでに芽が出なければ畳むか（撤退期限）

## 3. 当日の進行

### 60分の場合

| 時間 | 内容 | スライド |
|---|---|---|
| 0–5分 | 挨拶。**先に「本日のお願い2点」を言う** | 1, 2 |
| 5–10分 | 自己紹介と、いま動かしているもの | 3 |
| 10–25分 | 課題仮説〜解決仮説。**ここは説明より会話。指摘をもらう** | 4, 5, 6, 7 |
| 25–35分 | 現在地（できている／できていない）と90日計画 | 8, 9, 10 |
| 35–45分 | 5つの問い。Q4・Q5への所感をもらう | 11 |
| 45–55分 | 紹介のお願い、予備調査のご相談 | 12, 13 |
| 55–60分 | 次のアクションを口頭で確定して終わる | — |

### 30分の場合

2（サマリー）→ 9（現在地）→ 11（5つの問い）→ 13（お願い）だけ。
課題仮説・解決仮説は聞かれたら開く。**お願いに必ず10分残す。**

### 進め方の原則

- 資料を読み切ることが目的ではない。**紹介を1件もらうことが目的**
- 相手が話し始めたら資料を止める。指摘は全部メモする
- 反論しない。「それ、4つのうちどれが一番刺さりますか」と順位を聞く

## 4. 想定問答

**「で、今何社使ってるの？」**
> ゼロです。有償顧客も売上もありません。だから今日、ヒアリング先のご紹介を
> お願いしに来ました。

**「なぜ工場なの？」**
> 【要記入】。ここは言葉を用意しておくこと。詰まると一気に信用が落ちる。

**「競合はどうするの？既存の生産管理システムがあるよ」**
> 正面からは戦いません。最大の競合は他社製品ではなく「今のままで困っていない」
> という現状維持だと思っています。まず1社で使われ続ける型を作ることが先です。

**「現場は入力しないよ」**
> 同じ懸念を持っています。だから設計方針を「現場の作業を増やさない」に置きました。
> ただ、本当に入力されるかは机上では分からないので、PoCで確かめる項目にしています。

**「いくらで売るの？」**
> 仮置きで初期◯万円、月額◯万円／拠点です。決めた価格ではありません。
> 「いくらなら払うか」を客に聞いても本音は出ないので、
> 「今その課題に年間いくらかかっているか」を聞いて逆算する方針です。

**「ひとりでやるの？」**
> 【要記入】。稼働時間と資金を正直に。盛らない。

**「補助金は使わないの？」**
> 使える可能性はありますが、補助金を前提にした事業にはしません。
> 補助金が切れた瞬間に解約される作りになるからです。

**「で、うちに何をしてほしいの？」**（← これが出たら勝ち筋）
> ヒアリング先を1〜2社ご紹介ください。まずは1社で構いません。

**「予備調査、どうする？」**
> ありがたいお話です。判断基準は「その調査結果で自分の次の行動が変わるかどうか」
> だと思っています。スコープと費用感を伺った上で、○日までに返答させてください。

### 言ってはいけないこと

- 「なんでもできます」→ 何もできないと同義
- 「たぶん」「〜だと思います」の連発 → 分からないなら「分かりません、確かめます」
- 相手の指摘への反論 → 今日は情報をもらう場。議論に勝っても紹介は増えない

## 5. 予備調査を発注するかの判断

### その場で聞くこと

1. 典型的なスコープと期間（何を、どこまで、何週間で）
2. 費用のレンジ
3. 成果物の形（報告書か、示唆か、企業リスト付きか）
4. 調査後の支援の有無と、その費用

### 判断基準

**「その調査結果で、自分の次の行動が変わるか」**。変わらないなら今は買わない。

| 状況 | 判断 |
|---|---|
| Q1〜Q3（現場が入力するか／決裁者／価格）が知りたいだけ | **買わない。**自分で10社聞けば埋まる |
| Q4・Q5（既存システムとの共存、横展開の型）で詰まっている | 買う価値あり。ただし金額次第 |
| 調査の結果に関わらず、やることが同じ | **買わない** |
| 成果物に「会える企業リスト」が含まれる | 販路に直結するので価値が上がる |

**その場で即決しないこと。**「○日までに返答します」と期日を切って持ち帰る。
判断基準を先に言っておくと、無理な売り込みを受けにくく、かつ評価も上がります。

なお、予備調査は先方にとっての商材でもあります。悪い話ではありませんが、
提案されたから受ける、という順番にはしないこと。

## 6. 面談後24時間以内にやること

- [ ] お礼の連絡（当日中）。**もらった指摘を箇条書きで要約して返す**
      — ちゃんと聞いていた証明になり、次も協力してもらえる
- [ ] 紹介の口約束が出たら、**紹介文のたたき台をこちらから送る**
      （相手の手間をゼロにする。手間があると紹介は流れる）
- [ ] つなぎの方にも結果を共有する（この方が一番気にしている）
- [ ] 予備調査の返答期日をカレンダーに入れる
